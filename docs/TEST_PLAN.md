## 已知限制

- 音質因手機麥克風、環境與 Android 音訊策略而異，不保證無損。
- Android 12+ 顯示相機／麥克風使用指示；通知為預期的可見行為。
- 不申請 ACCESS_BACKGROUND_LOCATION；定位前景服務必須由使用者從畫面啟動。
- 使用 Android 原生 Camera2，不同裝置圖像旋轉與尺寸仍需實機檢查。
- 這是最小可運作版本，不包含遠端控制、後端同步、登入與加密資料庫。
