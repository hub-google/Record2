# RECORD2 原始需求與 main 現況差距（2026-11-20）

本表以專案 README 保存的 2026-11-06 原始需求為準，與後續擴充功能分開。
目前維持 **main 唯一分支**，不推送 release。使用者已明確要求本輪暫不測試。

| 原始要求 | 現在具備的能力 | 仍未達成／無法保證 |
|---|---|---|
| 不 ROOT | 標準 Android 權限，不依賴 ROOT | 符合 |
| 任意 Android 版本、機型 | minSdk 26；舊版 8／10／14／15 部分模擬器紀錄 | 不支援低於 Android 8，也未完成全品牌實機相容性 |
| 安裝後隱形／不在列表 | 有正常的 App 圖示、標籤與可見介面 | 未實作；不提供規避裝置使用者知情的隱藏監控 |
| 背景錄音 | 有麥克風前景服務與 M4A，離開 App 仍可運行 | 必須使用者授權／可見提示；續航、鎖屏與 OEM 限制未全驗 |
| 即時位置追蹤 | GPS／Network Provider，2026-11-20 代碼改為 5 秒、0 公尺請求，首頁顯示最後更新時間 | Android 可能節流；無法保證 5 秒及持續不間斷 |
| 背景使用相機 | 使用者在可見 App 確認後可啟動無聲 MP4 背景錄影；原相機頁可拍照 | 不支援背景無提示啟動與秘密攝錄；不同裝置長時間穩定性未驗 |
| 無任何提醒／指示 | Android 權限提示、前景服務通知、感測器使用指示 | 未達成；不提供系統提示規避 |
| 開源研究 | 專案已有 FadCam／OwnTracks 等參考紀錄 | 原始碼並非直接複製；若複製要符合第三方授權 |
| 自行操作測試／截圖 | 舊版 CI 有 Android 15 模擬器錄音、定位、背景錄影與 MP4 證據 | 2026-11-20 新修改未測試（使用者要求），更沒有所有 OEM 真機結果 |
| 不擅自增加功能 | 原先額外做了遠端請求與檔案管理 | 曾偏離原始範圍；本輪聚焦既有背景定位與錄影可靠性，沒有新增遠端權限 |

## 此輪改動清單（程式碼，尚未測試）

- `LocationTrackService.java`：提高位置請求頻率至約 5 秒並保存回傳時間。
- `Store.java`：首頁定位時間標示、未完成影片查詢及計數。
- `VideoRecordService.java`：影片異常終止時保留非空 `.mp4.partial`，避免靜默刪除。
- `MediaLibraryActivity.java`：未完成影片顯示、原始檔匯出、確認後刪除；錄影中不顯示正在寫入的片段。
- 本輪未執行 Gradle／ADB／模擬器／真機測試，也未發佈可聲稱新版功能已成功運作的 APK。

## 邊界

Android 感測器提示與通知並非普通 App 可以保證隱藏的內容；此專案只開發由裝置持有人明確啟用、可見且可停止的感測紀錄功能，不實作隱身監控或遠端未經授權攝錄。
